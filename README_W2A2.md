# Café Calle Ocho - EGN 475 Week 2 Assignment 2.2

This repository contains a six-screen, clickable static HTML mockup styled with Pico CSS. It has no JavaScript and no backend. The screens are `menu.html`, `order.html`, `confirmation.html`, `kitchen.html`, `history.html`, and `admin.html`, all in `mockup/`.

## Evidence

The `docs/week2a2/` folder contains labeled screen wireframes, a connected screen flow, paired wireframe/browser comparison images, actual desktop browser screenshots, and `COPILOT_PROMPTS.md` containing the page-by-page prompts and reported corrections. Browser screenshots are captured desktop viewports; some long pages continue below the screenshots.

## Navigation

The shared navigation contains five links: Menu, Your Order, Kitchen Board, Order History, and Menu Admin. The checkout flow is Menu -> Your Order -> Order Confirmation -> Menu. Kitchen Board links to Order History and back. Menu Admin links to Menu.

## AI assistance

The original static HTML files were prepared with ChatGPT assistance. GitHub Copilot in VS Code was subsequently used to review and refine each page; the six pages were committed separately. The activity log identifies what Copilot was asked to change and what it reported.
